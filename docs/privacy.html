개인정보처리방침

샵스토리(shopstory.kr) · 시행일 2026년 10월 30일

샵스토리(이하 "서비스")는 매장 홍보 영상을 만들어 주는 도구입니다. 이 방침은 서비스가 어떤 정보를 어떻게 다루는지 설명합니다.

1. 수집·이용하는 정보

  • 사용자가 입력·업로드하는 정보: 상호명, 주소, 메뉴 정보, 매장 사진·영상, 직접 입력한 문구. 영상 제작 목적으로만 사용합니다.
  • 유튜브 연동 정보: 사장님이 구글 로그인에서 허용한 경우, 업로드에 필요한 인증 토큰과 연결된 채널 이름·ID를 사용합니다.

서비스는 별도의 회원가입을 받지 않으며, 광고 목적의 개인정보 수집이나 이용자 추적을 하지 않습니다.

2. Google 사용자 데이터 (YouTube API)

  • 요청하는 권한: 영상 업로드(youtube.upload), 업로드한 영상에 첫 댓글 등록(youtube.force-ssl).
  • 사용 목적: 사용자가 만든 영상(매장·숙소·쇼핑 홍보 쇼츠)을 사용자 본인이 소유하고 직접 연결한 유튜브 채널에 올리고, 첫 댓글(매장 위치·검색 안내)을 등록하는 것. 이 목적 외에는 사용하지 않습니다.
  • 채널 구분: 용도별로 채널과 토큰을 따로 연결하며, 업로드 전에 연결된 채널이 맞는지 확인합니다. 한 용도의 토큰으로 다른 용도의 채널에 올리지 않습니다.
  • 저장: 인증 토큰은 서비스 운영 서버의 비공개 설정(Secrets)에 보관하며, 화면이나 로그에 노출하지 않습니다.
  • 공유·판매 금지: 구글 사용자 데이터를 제3자에게 판매하거나 광고에 사용하지 않으며, 서비스 제공 이외의 목적으로 공유하지 않습니다.
  • Limited Use: 샵스토리의 Google API 정보 사용과 다른 앱으로의 전달은 제한된 사용(Limited Use) 요건을 포함한 Google API Services User Data Policy를 준수합니다.
  • 연동 해제: 구글 계정 권한 관리에서 언제든 샵스토리의 접근 권한을 취소할 수 있습니다.

3. 외부 서비스 이용

영상 제작을 위해 아래 외부 서비스에 필요한 내용(상호명, 사진, 대본 문장 등)이 전달될 수 있습니다: 대본·사진 판독용 AI 서비스(Anthropic, OpenAI, Google Gemini), 음성 합성(Microsoft Edge TTS, Google TTS), 네이버 검색·플레이스 정보 조회. 각 서비스는 자체 약관과 개인정보 정책에 따릅니다.

4. 보관과 삭제

업로드한 사진·영상과 제작 결과물은 영상 제작을 위해 서비스 서버의 작업 공간에 보관될 수 있습니다. 삭제를 원하시면 아래 이메일로 요청해 주세요. 확인 후 삭제합니다.
