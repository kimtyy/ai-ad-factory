샵스토리

AI 사장님 매장 홍보 영상 제작소 · shopstory.kr

샵스토리는 동네 가게 사장님이 가게 이름을 입력하고 매장 사진·영상을 올리면, 한 컷에 한 줄 카피가 붙은 세로형(9:16) 홍보 쇼츠와 업로드용 제목·본문·해시태그를 만들어 주는 도구입니다.

주요 기능

  • 가게 정보(상호·주소·대표 메뉴) 불러오기와 사진·영상 업로드
  • 사진 속 메뉴를 확인해 대본(한 컷 한 줄 카피) 작성, 자막·음성이 들어간 쇼츠 영상 제작
  • 유튜브 쇼츠·인스타그램 릴스·네이버 클립·틱톡에 올릴 제목·본문·해시태그 문구 제공
  • 사장님이 직접 허용한 경우에 한해, 완성한 영상을 사장님의 유튜브 채널에 업로드하고 첫 댓글을 등록
  • 같은 방식으로 숙소·쇼핑 홍보 쇼츠도 만들 수 있으며, 각 영상은 사장님이 연결한 해당 용도의 본인 채널에만 올라갑니다

유튜브 연동에 대하여

샵스토리는 사장님 본인이 소유한 유튜브 채널에 영상을 올리고 첫 댓글을 다는 용도로만 YouTube API를 사용합니다. 매장·숙소·쇼핑 용도별로 채널을 따로 연결하며, 연결된 채널이 아닌 곳에는 업로드하지 않습니다. 영상 업로드와 댓글 등록 권한만 요청하며, 다른 사람의 채널이나 데이터는 사용하지 않습니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.
